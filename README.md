Виртуальное окружение есть, название venv (старт venv\Scripts\activate).
В settings при тестировании поменять настройки БД (тестировалось на postgres).
Необходимо сделать фильтрацию по семестрам и, возможно, переработать какие-то функции под фронт. Прикрутить фронт и панель админа.

Тестирование проходилось после старта бэка (python manage.py runserver)
Посмотреть текущую ведомость:
http://127.0.0.1:8000/api/statements/current/?user_id=1
Посмотреть ведомости пользователя:
http://127.0.0.1:8000/api/statements/?user_id=1
Создать ведомость из пересдачи
http://127.0.0.1:8000/api/statements/create/1/
Детали пересдачи
http://127.0.0.1:8000/api/retakes/1/
Список пересдач
http://127.0.0.1:8000/api/retakes/

Новый sql запрос там же с названием newquery.

Если зависимости не установлены:
pip install -r requirements.txt
Версию python лучше не ниже 3.10
