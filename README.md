# Resit Statements Backend

Backend часть системы формирования ведомостей для пересдач.

Проект реализован на **Python + Django + Django REST Framework** и предоставляет API для работы с пересдачами и ведомостями.

# Требования

Для запуска проекта необходимо:

- **Python 3.10 или выше**
- **PostgreSQL**
- Установленные зависимости из `requirements.txt`

---

# Установка зависимостей

В проекте уже присутствует виртуальное окружение `venv`.

Активировать его можно командой: `venv\Scripts\activate`.

Если зависимости ещё не установлены: `pip install -r requirements.txt`.


---

# Запуск проекта

После активации виртуального окружения запустите backend сервер:
`python manage.py runserver`

---

# Настройка базы данных

Перед запуском необходимо изменить настройки подключения к базе данных в файле: `backend/settings.py`

Проект тестировался с использованием **PostgreSQL**, поэтому параметры подключения необходимо указать в соответствии с вашей конфигурацией.

SQL-скрипт для создания структуры базы данных находится в файле: `newquery.sql`

Его необходимо выполнить в PostgreSQL перед запуском проекта.

# Тестирование API

Тестирование проводилось после запуска backend сервера.

---

## Список пересдач
GET http://127.0.0.1:8000/api/retakes/

---

## Детали пересдачи
GET http://127.0.0.1:8000/api/retakes/1/

---

## Создание ведомости из пересдачи
POST http://127.0.0.1:8000/api/statements/create/1/


---

## Текущая ведомость пользователя
GET http://127.0.0.1:8000/api/statements/current/?user_id=1


---

## Все ведомости пользователя
GET http://127.0.0.1:8000/api/statements/?user_id=1


---

# Дальнейшая доработка

Для полного функционирования системы необходимо:

- реализовать **фильтрацию пересдач по семестрам**
- адаптировать некоторые функции под требования **frontend**
- интегрировать **frontend часть**
- подключить и настроить **панель администратора**
